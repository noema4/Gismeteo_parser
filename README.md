# 🌦️ Gismeteo Parser
Парсер погоды на Python для сайта Gismeteo с интерактивным выбором города, несколькими вариантами прогноза и экспортом данных в CSV.

# ✨ Возможности
- 🏙️ Выбор города — укажите город, для которого хотите получить прогноз погоды.
- ☀️ Погода на сегодня — просмотр текущего прогноза на день.
- 🌤️ Погода на завтра — получение прогноза на следующий день.
- 📅 Прогноз на 7 дней — просмотр погоды на ближайшую неделю.
- 📊 Экспорт в CSV — сохранение данных о погоде в файл для дальнейшего анализа.
